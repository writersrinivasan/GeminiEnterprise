# Gemini Enterprise Training Sandbox 🌈

An **unofficial**, colorful, fully simulated workspace for learning how a Gemini Enterprise-style
platform works, before (and alongside) official training. Everything runs in your browser. The company
"Nimbus Outfitters" and all of its docs, emails, tickets and deals are fictional. There is no real AI and
no Google account connection.

## Run it
```bash
npm install
npm run dev        # http://localhost:3100
```

## What's inside
| Area | What you practise |
|---|---|
| 🏠 Home | Greeting + prompt box, next mission, learning path |
| 💬 Chat | Grounded answers, citations, "Show thinking" (RAG steps), source toggles, web grounding, permission (ACL) demo |
| 🤖 Agents | Gallery of prebuilt agents (Idea Generation, Data Insights, IT Help Desk, Deep Research, NotebookLM) |
| 🛠️ Agent Designer | No-code agent: identity, instructions (live quality score), knowledge, tools, starters, live test, publish |
| ⚙️ Workflows | Trigger → AI steps → actions, templates, animated run log, human approval (approve/reject) |
| 🔌 Connectors | Simulated OAuth, scope, ingested vs federated mode, sync progress |
| 🔬 Deep Research | Editable research plan → live activity feed → cited report → save to NotebookLM |
| 📓 NotebookLM | Notebooks with chosen sources, source-only chat, study guide / FAQ / briefing / mind map / audio overview |
| 🛡️ Admin | Licenses, feature policies, Model Armor, data residency, audit log, usage analytics |
| 📚 Learn | 9 modules with quizzes |
| 🧪 Labs | 8 self-checking labs (37 tasks), XP, levels, 16 badges, confetti |

Progress is saved in `localStorage`. Use **My progress → Reset sandbox** to start over.

> Screens and feature names are approximations made for learning. Check Google's official
> documentation for current product details, editions and pricing.
